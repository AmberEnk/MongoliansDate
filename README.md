# Mongolian Makers Market

Phase 1 preview of the marketplace homepage. Mongolian is the default language. English is at `/en`. Makers, products, and prices are sample data.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). The root path redirects to `/mn`.

```bash
npm run build
npm run lint
```
